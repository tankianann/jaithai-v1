# M3.2C — Vegan Catering Menu Replacements

**Status:** Implemented

**Delivery phase:** Phase 3 — Catering-menu update

**Roadmap:** [`../roadmap/roadmap.md`](../roadmap/roadmap.md)

## Outcome

Replace Vegan Catering Menus A–C with the approved Vegan Essential, Classic, and Signature Thai Buffet content, and introduce Vegan Catering Menu D with the approved Vegan Supreme content and supplied card image.

## Implemented Scope

- Replaced every fixed dish and selectable dish group in `VEGEA`–`VEGEC` with its mapped supplied menu content.
- Added `VEGED` as the stable ID for Vegan Catering Menu D and registered it with the existing menu lookup and administration selector.
- Added the native `/jtmenu/vegetarianmenud` controller route and catering collection card without adding a legacy `.php` redirect.
- Updated the per-pax prices to $15, $18, $21, and $24 respectively.
- Preserved the approved minimums of 40 pax for Menu A and 30 pax for Menus B–D.
- Updated course counts, descriptions, metadata, landing-page summaries, form defaults, and submitted field capture to match the supplied menus.
- Added the full supplied dessert list to all four menus, retaining Mango Sticky Rice at the existing `$1.00 Per Pax` surcharge and leaving Tako surcharge-free.
- Used ordinary radio buttons for all supplied choice groups, including the Clear/Chilli Paste Vegan Tom Yum Soup choice in Menu D.
- Kept drinks outside the included courses and retained the existing add-on-drink selector.
- Copied the supplied Vegan Catering Menu D image unchanged into the catering-menu assets and wired it to the new card.
- Expanded smoke-test coverage to load all four Vegan Catering forms and add Menu D to the cart.

## Functionality Assessment

Menu D required a small functional expansion: a new stable menu ID, native controller route, registry and administration-selector entries, display-layout registration, and collection card. It reuses the existing set-menu renderer, radio controls, surcharge handling, cart model, and database schema.

## Explicit Exclusions

- No `/vegetarian-menu-d.php` legacy redirect was added, at the user's direction.
- No new renderer control, pricing mechanism, database field, or schema change was introduced.
- Existing dish photography and the known catering-tab behavior remain unchanged.
