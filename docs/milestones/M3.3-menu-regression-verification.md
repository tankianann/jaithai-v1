# M3.3 — Menu Regression Verification

**Status:** Complete

**Delivery phase:** Phase 3 — Catering-menu update

**Roadmap:** [`../roadmap/roadmap.md`](../roadmap/roadmap.md)

## Outcome

Provide repeatable regression checks for the Set, DIY, and Vegan Catering A–D replacements, then use the live local test surface to verify their rendered forms and representative cart behavior.

## Implemented Scope

- Added `bin/menu-regression.php`, a PHP 7.4-compatible host-side command that requires no Docker service, database, or network access.
- Covered all twelve menu definitions, including stable IDs and customer-facing names, approved prices and minimums, course counts, supported renderer controls, nonempty labels, and removal of menu-specific halal wording.
- Verified Tako remains surcharge-free and Mango Sticky Rice retains the existing `$1.00 Per Pax` surcharge in every updated menu.
- Verified every selectable field is covered by the corresponding controller action's defaults and POST capture.
- Verified the supplied curry and Tom Yum groups use ordinary radio choices rather than the Regular/Vegan dropdown.
- Verified Vegan Menu D's registry, native route card, display layout, administration selector, supplied image, and deliberate lack of a legacy `.php` redirect.
- Covered the v1-only rendering exception that displays set-menu dishes without numbering for legacy order database ID `12977`, including its administration, customer-email, order-details PDF, and delivery-order PDF view wiring. This order-ID allowlist must not be carried into v2; any equivalent future behavior should be represented explicitly in v2 order data.
- Documented the menu-regression command alongside the existing local smoke suite.

## Verification Result

- `php -l bin/menu-regression.php` passes under the available host PHP runtime.
- The original menu-delivery baseline passed 173 checks with zero failures. The later legacy-order regression coverage increased the suite to 181 checks.
- The current suite passes all 181 checks under PHP 7.4 using `docker compose run --rm --no-deps web php /opt/jaithai/bin/menu-regression.php` when the services are stopped, or the equivalent `docker compose exec -T web ...` command when they are running.
- `docker compose exec -T web php /opt/jaithai/bin/smoke-test.php` passes 106 checks with zero failures, including all twelve menu forms and representative Set, DIY, and Vegan cart submissions.
- The smoke run confirms MariaDB connectivity, fixture integrity, administration pages, access controls, and PDF generation, with fixture row counts unchanged.
- The user confirmed completion of the manual browser review on 2026-10-01.
