# Project Decisions

Store architecture decision records and other material project decisions here. Use one durable Markdown file per decision, give it a stable identifier and descriptive name, and record its status, context, decision, consequences, and affected roadmap milestones.

Keep unresolved decision gates in `../roadmap/roadmap.md`. Once a decision is made, add its record here and link it from the gate and every milestone whose scope or acceptance criteria it changes.
